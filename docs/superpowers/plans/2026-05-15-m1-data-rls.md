# M1 Data Model, RLS, And Seeds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish the P0 Supabase schema, Row Level Security policies, seed data, and deterministic text/profile helper functions.

**Architecture:** Database structure lives in Supabase migrations and seed files. Deterministic business helpers live in small domain modules under `lib/posts` and `lib/profiles`, with tests proving slug, excerpt, and username behavior before UI integration.

**Tech Stack:** Supabase SQL migrations, PostgreSQL RLS, TypeScript, Vitest.

---
