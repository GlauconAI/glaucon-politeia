> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make authenticated user identity stable, editable, and safely visible through profile routes.

**Architecture:** Profile invariants live in `lib/profiles`. Route pages stay thin: `/profile/me` resolves the current user, while `/profile/[username]` renders public profile data and owner-only edit/bookmark surfaces.

**Tech Stack:** Next.js App Router, Supabase SSR/Storage, TypeScript, Vitest.
