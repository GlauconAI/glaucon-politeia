🧭 整体路线

这版路线分成前后两个同行阶段。前半段是 Kathy 家和 Cindy 家先出发，在 Nanaimo 汇合，一起完成 Nanaimo 两晚和 Port Alberni 过渡夜。7/29 是人员切换日：Kathy 家和 Cindy 家从 Port Alberni 继续进 Ucluelet，完成 Wild Pacific Trail 和钓螃蟹后，Cindy 家下午或晚上结束前半段；Mary / Mark 从 Metrotown 出发，坐 ferry 到 Nanaimo，再开车进 Ucluelet，与 Kathy 家汇合，之后一起完成 Ucluelet 两晚和 Green Point 两晚露营收尾。

主路线： Vancouver → Ferry → Nanaimo → Parksville / Rathtrevor → Port Alberni → Highway 4 → Ucluelet → Pacific Rim / Long Beach → Green Point Campground → Nanaimo Ferry → Vancouver

Kathy 家： Coquitlam / Vancouver → Horseshoe Bay → BC Ferry → Nanaimo / Departure Bay

Cindy 家： Victoria → Malahat → Nanaimo

前半段汇合后： Nanaimo → Parksville / Rathtrevor → Coombs → Port Alberni

Cindy 家前半段结束： 7/29 在 Ucluelet 完成 Wild Pacific Trail / 钓螃蟹后，下午或晚上返程，具体返程路线待确认

Mary / Mark 后半段加入： 7/29 Metrotown → Horseshoe Bay → BC Ferry → Nanaimo / Departure Bay → Highway 4 → Ucluelet

后半段汇合后： Ucluelet → Pacific Rim / Long Beach → Green Point Campground → Nanaimo Ferry → Vancouver

核心变化： 出发从 7/25 改为 7/26；新增 Port Alberni 过渡夜；取消 Tofino 住宿；Mary / Mark 不参加 Day 1，而是 7/29 直接加入后四天；Ucluelet 成为后半段室内住宿主基地；Green Point 两晚保持不变。
